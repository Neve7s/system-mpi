# Lectura de planos sin API de pago — V1.3

La tienda conserva el lector local del navegador. Abre la calculadora, carga un JPG, PNG, WEBP o PDF y selecciona **«Leer plano en mi navegador»**. Se detecta el soporte de IA integrada; cuando no exista, se usa extracción textual/OCR disponible o ingreso manual. Nunca se envían los planos a un servicio OpenAI de pago desde esta versión. La descarga inicial de bibliotecas OCR puede necesitar internet.

Revisa todas las cotas, unidades, faldones y pendientes. No infieras medidas faltantes solo por escala visual. Una lectura automática no sustituye planos verificados ni criterio técnico de instalación. No se probó la IA integrada de Chrome con modelos reales en este entorno de auditoría.
